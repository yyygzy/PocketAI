## 1. 认识墨匣

墨匣是一个**本地优先、可以随身携带**的 AI 工作台。

**它的三个核心特点：**

- **数据都在你手里**：对话记录、知识库、API 密钥全部保存在你电脑（或 U 盘）上，不上传任何第三方服务器。
- **一个文件夹，带走就走**：把软件放进 U 盘/移动硬盘，你的全部数据和设置就在里面，插到任何电脑都能直接用。
- **Windows、Linux 通用**：同一份数据，Windows 便携版和 Linux 便携版都能打开。

**它能做什么：**

| 功能 | 说明 |
|---|---|
| AI 对话 | 接入你自己的模型（如 OpenAI、DeepSeek 等兼容接口），多轮聊天、重新生成、消息分支 |
| 助手 | 预设不同人设（写作、编程、翻译……），每个助手独立配置 |
| 知识库 | 导入 PDF / Word / Excel / TXT / Markdown 等文档，让 AI 基于你的资料回答 |
| 智能体（Agent） | AI 可以调用工具：搜索网页、读取文件、执行计算、查天气、读日历等 |
| 翻译 / 图片生成 / 笔记 / 文件管理 | 常用工具模块 |
| 隐私保护 | 主密码加密数据库、自动锁屏、离开手动锁定 |
| 备份 | 本地备份或自动备份到 WebDAV 网盘 |

## 2. 下载与安装

### 2.1 三个版本怎么选

在发布页（GitHub Releases）会看到三个文件：

| 文件名 | 适合谁 |
|---|---|
| `Moxia-1.0.0-x64.exe` | **Windows 安装版**：固定装在一台电脑上，有开始菜单快捷方式 |
| `Moxia-1.0.0-Portable-x64.exe` | **Windows 便携版**：放进 U 盘/移动硬盘，即插即用（推荐） |
| `Moxia-1.0.0-Linux-x86_64.AppImage` | **Linux 便携版**：Ubuntu 等 Linux 系统，赋予执行权限后双击运行 |

> 下载地址：<https://github.com/yyygzy/PocketAI/releases/latest>

### 2.2 Windows 安装版

双击 `Moxia-1.0.0-x64.exe`，按向导选择安装目录即可。安装后桌面和开始菜单会有墨匣图标。

### 2.3 Windows 便携版（U 盘用法）

1. 把 `Moxia-1.0.0-Portable-x64.exe` 复制到 U 盘（或电脑任意文件夹）。
2. 双击运行。
3. 软件会在**同一个文件夹**里自动创建 `data` 目录——你的所有数据都在里面。

```
U:\Moxia\
├── Moxia-1.0.0-Portable-x64.exe   ← 程序本体
├── data\                              ← 你的全部数据（备份它就够了）
│   ├── app.db                         ← 对话、知识库、设置
│   ├── attachments\                   ← 附件
│   └── logs\                          ← 日志
├── extensions\                        ← 助手/技能扩展
└── runtime\                           ← 便携运行时（如有）
```

**换电脑使用**：直接把 U 盘拔下来插到另一台 Windows 电脑，双击 exe，数据原样在。

### 2.4 Linux 版

```bash
chmod +x Moxia-1.0.0-Linux-x86_64.AppImage
./Moxia-1.0.0-Linux-x86_64.AppImage
```

数据目录同样创建在 AppImage 文件旁边的 `data/` 文件夹（AppImage 自身是只读的）。

### 2.5 Windows + Linux 双系统共用一个 U 盘

把两个程序文件放在 U 盘同一目录，共享同一个 `data/`：

```
U:\Moxia\
├── Moxia-1.0.0-Portable-x64.exe
├── Moxia-1.0.0-Linux-x86_64.AppImage
└── data\        ← 两个系统读写同一份数据
```

> 建议第一次跨系统使用后，检查一遍对话、知识库、密钥是否完整。

## 3. 第一次启动（引导向导）

首次打开会进入 4 步向导：

1. **硬件检测**：软件自动查看你的电脑配置，给出模型选择建议（低配/高配适合什么规模的模型）。
2. **服务商配置**：填入你的模型 API 密钥（见下一节）。
3. **加密设置**：选择是否设置主密码（详见第 10 节）。
4. **完成**：进入主界面。

> 如果用的是便携盘且换了一台电脑，再次启动会出现**精简版重新检测向导**（机器指纹变了），确认环境即可，数据不受影响。

## 4. 接入你的 AI（配置服务商）

墨匣本身不提供大模型，需要你填入自己的模型服务密钥（支持所有 **OpenAI 接口兼容**的服务商）。

**操作路径：左侧边栏 ⚙️ 设置 → 模型服务商**

1. 点击「新增服务商」。
2. 填写：
   - **名称**：随便取，如"我的 DeepSeek"
   - **接口地址（Base URL）**：服务商提供，如 `https://api.deepseek.com/v1`
   - **API 密钥**：在服务商官网申请
3. 点击「测试连接」，显示成功后保存。
4. 点击「获取模型列表」可以拉取该账号可用的模型。

> 🔒 API 密钥在本地加密存储（字段级加密），不会随对话发送给除该服务商以外的任何地方。

常见服务商（地址以其官网文档为准）：OpenAI、DeepSeek、月之暗面 Kimi、智谱、通义千问、本地 Ollama（`http://localhost:11434/v1`）等。

## 5. 开始对话

### 5.1 基本操作

- 左侧边栏点「新对话」开始聊天。
- 底部输入框输入内容，回车发送（`Shift+回车` 换行）。
- 回复过程中可点「停止」中断。
- 对话支持 Markdown 排版、代码高亮、数学公式（KaTeX）、流程图（Mermaid）。

### 5.2 标签页（像浏览器一样用）

- 顶部标签栏可同时打开多个对话/模块。
- 标签支持：**拖拽排序**、右键「关闭其他/关闭右侧」、双击重命名。
- 标签布局会记住，下次启动自动恢复。
- 标签上的「弹出」图标可把该模块**弹出为独立窗口**。

### 5.3 消息分支（重要特色）

对 AI 的某次回答不满意，点「重新生成」时，**旧回答不会被覆盖**——它会形成一条"分支"：

- 每一轮可以有多个候选回答，点分支导航（BranchNav）在不同版本间切换。
- 可以选两个回答点「⇄ 对比」并排查看，挑最满意的一条「激活」为正式上下文。
- 后续对话基于你激活的那条继续，其他分支保留，随时可回看。

### 5.4 对话管理

左侧对话列表支持：新建、重命名、删除、搜索消息内容、导出（JSON）、导入、从某条消息分叉（fork）。

## 6. 助手：让 AI 扮演不同角色

「助手」= 一套预设的人设和参数（系统提示词、默认模型、可用工具、绑定的知识库与技能）。

**入口：边栏「助手」模块**

- 内置助手来自 `extensions/assistants/` 目录，也可以自己创建。
- 创建助手时可设置：名称、头像、系统提示词、默认模型与温度等参数、允许使用的工具、关联技能和知识库、欢迎语。
- 免费版最多自建 **3 个**助手；激活专业版后不限。
- 助手可置顶（pinned）、复制（duplicate）。

## 7. 知识库：让 AI 读你的资料

### 7.1 创建知识库

边栏「知识库」→ 新建，命名后即可添加文件。

**支持的文件类型：**

- PDF（`.pdf`）
- Word（`.docx`）
- Excel（`.xlsx`）
- 纯文本/Markdown（`.txt` `.md`）
- 网页等其他文本格式

### 7.2 工作原理（简单理解）

1. 文件导入后被切成小块（chunk）；
2. 通过你配置的模型生成向量（embedding）；
3. 提问时找出最相关的几块内容喂给 AI，实现"基于你的资料回答"（RAG）。

> 向量相似度使用纯 JS 余弦相似度计算，不依赖任何系统原生组件，因此跨平台、跨电脑都能正常读取。

- 免费版最多创建 **1 个**知识库；专业版不限。
- 文档可重新索引、删除；知识库可删除（不影响原始文件）。

## 8. 技能与 MCP：给 AI 装"工具"

### 8.1 内置工具

智能体（Agent）模式下，AI 可使用的内置工具包括：

| 工具 | 作用 |
|---|---|
| `time_now` | 获取当前时间 |
| `calculator` | 精确计算 |
| `web_search` | 联网搜索 |
| `web_fetch` | 抓取网页正文 |
| `weather.query` | 查天气 |
| `calendar_read` | 读取 ICS 日历 |
| `js_eval` | 在隔离沙箱里运行 JavaScript（无文件/网络权限） |
| `fs_list/read/write` | 文件操作（**仅当设置了工作目录时可用**，禁止越界路径） |
| `shell_exec` | 执行系统命令（**默认关闭**，且有拦截/确认机制，见第 10.4 节） |

### 8.2 工具调用安全

- AI 要执行有风险操作（写文件、跑命令等）时，会弹出**审批对话框**，完整显示命令内容和风险提示，**你同意了才执行**。
- 审批对话框 5 分钟无操作自动拒绝。
- 危险命令（如格式化、删除系统目录）在黑名单中，即使允许也会被直接阻止。

### 8.3 技能（Skills）

技能是一段可复用的指令/能力包（JSON 形式，存放在 `extensions/skills/`），支持导入导出、技能市场浏览。

### 8.4 MCP 服务器

支持 MCP（Model Context Protocol）协议接入外部工具服务器，在「设置 / MCP」中配置。MCP 协议实现为零依赖轻量版。

## 10. 隐私保护：加密与锁屏

这是墨匣的重点能力，建议每个人都了解。

### 10.1 两种加密模式

| 模式 | 说明 | 适合 |
|---|---|---|
| 无密码（none） | 打开即用；API 密钥等仍有基础混淆保护 | 只用自己电脑、图方便 |
| 主密码（db） | 整个数据库 SQLCipher 加密，启动/解锁必须输密码 | U 盘携带、笔记本、重视隐私 |

**设置路径：设置 → 隐私与加密 → 启用加密**，输入主密码（至少 6 位）即可。

> ⚠️ **主密码无法找回**。启用时请立刻按提示保存**恢复密钥**（Recovery Key），它是忘记密码时唯一的补救途径，请离线妥善保管（不要和 U 盘放在一起）。

### 10.2 自动锁屏

**设置 → 隐私与加密 → 自动锁屏**，可选：永不 / 1 / 5 / 15 / 30 / 60 分钟无操作自动锁定。

锁定后：

- 所有窗口（含弹出的独立窗口）同步显示锁屏遮罩；
- 屏幕背后的内容被 `inert` 冻结，键盘和读屏无法穿透；
- 数据库密钥从内存清除，必须重新输入主密码才能继续。

### 10.3 手动锁屏（临时离开座位）

三种方式任选：

- 按 **`Ctrl + L`**（Mac 为 `Cmd + L`）；
- 点左侧边栏底部的 🔒「锁定」按钮；
- 菜单中选择锁定。

### 10.4 其他隐私机制

- **剪贴板保护**：复制到剪贴板的敏感内容可自动清除。
- **命令执行管控**：shell 命令分黑名单/需确认/白名单三类；`shell_exec` 默认关闭，需在助手设置里显式开启。
- **路径防穿越**：文件工具会阻止 `../`、绝对路径、UNC 路径、NUL 注入等越界访问。
- **CSP 内容安全策略**：渲染界面禁止加载任意远程脚本。
- **外部链接**：打开外链有协议白名单控制。

## 11. 授权激活（专业版）

### 11.1 三个版本区别

| | 免费版 | 个人专业版 pro | 企业版 enterprise |
|---|---|---|---|
| 自建助手数量 | 最多 3 个 | 不限 | 不限 |
| 自建知识库数量 | 最多 1 个 | 不限 | 不限 |
| 功能解锁 | 基础功能 | 签发的功能列表（默认全量） | 现有及未来全部功能 |
| 获取方式 | 不激活即是 | 购买/获发激活码 | 企业采购 |

> 不输入任何激活码 = 免费版，开箱即用，无需注册。

### 11.2 如何激活

1. 向软件提供方获取**激活码**（一段 `.lic` 文件或 JSON 文本）。
2. 打开 **设置 → 授权激活**。
3. 两种方式任选：
   - 点「激活」选择 `.lic` 文件导入；
   - 点「粘贴激活码」，粘贴文本后确认。
4. 验签通过立即生效，显示授权对象与版本。

**关于激活码你需要知道的：**

- 激活过程**完全离线**，不需要联网，也没有激活服务器。
- 激活码与机器绑定；重装系统/换机时重新激活即可。
- 激活码有有效期（永久买断版到期时间为 2099 年）。
- 激活码由软件提供方用私密密钥签发，应用内置公钥验证真伪——请只信任官方渠道获取的激活码。

## 12. 备份与恢复

**入口：设置 → 备份**

### 12.1 本地备份

- 手动「立即备份」：把数据库、附件等打包成一个 zip（可选择加密备份，加密备份会设置独立口令）。
- 建议定期把备份文件复制到 U 盘/网盘。

### 12.2 WebDAV 网盘备份

支持任何 WebDAV 协议的网盘（如坚果云、Nextcloud 等）：

1. 填写服务器地址、账号、密码（本地加密保存）；
2. 可「测试连接」；
3. 支持定时自动备份、**增量备份**（只传变化部分，省流量）；
4. 需要时在新设备「从 WebDAV 恢复」。

### 12.3 最简单的"笨办法"（便携版）

直接把整个 `data` 文件夹复制一份即可——它就是你的全部数据。**复制前请先退出软件。**

## 15. 常见问题（FAQ）

**Q1：双击程序后看不到窗口？**
依次排查：
1. 看任务栏/系统托盘是否已有墨匣在运行（单实例程序，重复双击只会激活已有窗口）；
2. 检查是否被杀毒软件（如腾讯电脑管家、360）拦截了网络服务进程——若是，将墨匣加入**信任区/白名单**后重启；
3. 便携版请确认整个文件夹没有被放在压缩包内（必须先解压再运行）；
4. 查看 `data/logs/` 下的日志。

**Q2：杀毒软件报毒/拦截？**
墨匣未购买代码签名证书时，Windows SmartScreen 可能提示"未知发布者"，属于正常现象，选择"仍要运行"即可；国产杀软可能误杀内置网络服务进程，加入信任区即可。

**Q3：我的数据存在哪？**
全部在程序旁边的 `data/` 文件夹（便携版）或安装目录/应用数据目录（安装版）。设置页底部"路径"区域可以看到实际位置。

**Q4：忘记主密码怎么办？**
用启用加密时保存的**恢复密钥**重置。恢复密钥也丢了的话，数据库无法解密——这是本地加密的代价，请务必提前保存恢复密钥。

**Q5：把 U 盘插到别的电脑，要重新输 API 密钥吗？**
- 无密码模式：不用，密钥可被自动解出，直接用。
- 主密码模式：输入你的主密码即可解密全部数据。

**Q6：换机后出现"环境重新检测"向导？**
正常现象。软件通过机器指纹识别到运行环境变化（防盗用激活码/加密保护），确认一遍即可，数据完整。

**Q7：免费版和专业版的数据格式一样吗？升级会丢数据吗？**
完全一样。激活只是解锁数量限制，不改变任何数据；随时可以从免费版升级到专业版。

**Q8：如何彻底卸载？**
- 安装版：系统设置 → 应用 → 卸载。
- 便携版：直接删除整个文件夹即可（不写注册表）。删除前请确认已备份 `data/`。

**Q9：AI 回复很慢 / 报错？**
- 先到设置里点「测试连接」确认服务商和密钥正常；
- 硬件较差时在管家中参考模型推荐，选择更小的模型；
- 错误信息会直接显示在对话中，常见为密钥余额不足、网络不通、模型名错误。

提交 Issue：<https://github.com/yyygzy/PocketAI/issues>，附上 `data/logs/` 中的相关日志（提交前可自行删除日志里的敏感信息）。
